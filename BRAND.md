# Kharis homepage — brand bits we used

## Font
- Plus Jakarta Sans (Google Font)
- Body: medium/semibold
- Headings / big titles: bold / extra bold

## Main colours
- Purple (brand): `#6B34FA`
- Darker purple (hover): `#5420D6`
- Orange (accent): `#FD7F20`
- Soft purple background: `#F1ECFF`
- Soft off-white background: `#F8F6FC`
- Page white: `#FFFFFF`
- Main text: `#1C1C1F`
- Soft text: `#3A3A40`
- Grey / muted text: `#6E6E76`

## Buttons (CTAs)
- Main site buttons → **purple** `#6B34FA` (hover `#5420D6`), white text
- Strong / give / highlight → **orange** `#FD7F20`, white text
- Header “Find a Branch” on the dark hero → light/white style; after scroll → orange
- Branch slideshow buttons → white with dark text

## Simple rule
Purple = main brand + most CTAs  
Orange = energy / give / special accents  
Light purple backgrounds behind soft sections
