# Daily Message

Daily Message chooses the sermon the Kharis app plays on a given day.

<Screenshot name="daily-message" alt="Daily message screen with a date, a sermon search showing results for grace, and upcoming scheduled messages" />

## Scheduling a message

1. Pick the **Date**. It opens on today.
2. Under **Sermon**, search by title, speaker, or scripture. Results appear after two letters.
3. Choose a sermon from the results. It's shown in a highlighted box, with **Change** if you picked the wrong one.
4. Add a **Note** if you'd like a line shown with the message.
5. Press **Schedule**.

::: warning One message per day
Scheduling a date that already has a message replaces it. To change a day, press **Edit** on it rather than adding it again.
:::

## Where the sermons come from

The search looks in the app's sermon catalogue: the messages mirrored into Cloudflare from the church's sermon host, with audio, video, and transcripts. These are not the records under [Sermons](/studio/sermons) in General. Browse the catalogue on its own in [Sermon Library](/mobile-app/sermon-library).

## Upcoming and Earlier

The right-hand side lists **Upcoming** messages from today onwards, and **Earlier** ones, most recent first. Each shows the date, sermon title, and note.

| Button | What it does                                                     |
| ------ | ---------------------------------------------------------------- |
| Edit   | Loads the day into the form. Save with **Update**, or **Cancel** |
| Delete | Removes the day, after asking                                    |

If a scheduled sermon has since left the catalogue, it shows as **Not in the sermon catalogue**. Edit the day and choose another.

Super admins only.
