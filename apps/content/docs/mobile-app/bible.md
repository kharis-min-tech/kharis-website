# Bible

Bible is where you check that a reading will open properly in the app. It doesn't store any Bible text.

<Screenshot name="bible" alt="Bible page with a reference checker and a list of upcoming daily readings" />

## Checking a reference

Type a reference into **Check a reference**. You can write several, separated by semicolons:

```
Romans 8:1-11; Psalm 23
```

Underneath, the studio says what the app will open, for example **Opens Romans 8:1-11, Psalm 23 in the Bible reader.** If it can't read the reference, the message turns red and explains why.

## Daily readings

Below the checker are the next eight [Daily Readings](/mobile-app/daily-reading), each with the passage the app will open. A reading without a reference shows **No reference, so the reader will not open a passage.**

Press **Edit readings** to fix any of them.

::: tip Where the words come from
The phone loads passage text from YouVersion. The default translation is NIV.
:::
