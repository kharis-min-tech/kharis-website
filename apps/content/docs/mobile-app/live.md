# Live

Live controls the broadcast in the Kharis app: what it's called, where it streams from, and whether it's on now.

<Screenshot name="live" alt="Live settings with Title, Stream URL and a Live now toggle" />

## Settings

| Field      | Notes                                                 |
| ---------- | ----------------------------------------------------- |
| Title      | Shown in the app, for example **Sunday Service Live** |
| Stream URL | The link to the stream                                |
| Live now   | Turn on when the broadcast starts, off when it ends   |

Press **Save**. You'll see **Live settings saved**.

## On a Sunday

1. Before the service, check the **Title** and **Stream URL**.
2. When the stream starts, turn on **Live now** and press **Save**.
3. When it ends, turn **Live now** off and save again.

::: warning Remember to turn it off
The app shows the broadcast as live for as long as **Live now** is on. Leaving it on sends people to a stream that has ended.
:::

Super admins only.
