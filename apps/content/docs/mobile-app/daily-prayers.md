# Daily Prayers

Daily Prayers sets the prayer shown in the Kharis app each day. It works like [Daily Reading](/mobile-app/daily-reading), but is stored separately.

<Screenshot name="daily-prayers" alt="Daily prayers list with a prayer for each date" />

## Adding a prayer

Press **New** and fill in:

| Field     | Notes                                                    |
| --------- | -------------------------------------------------------- |
| Date      | The day the prayer appears                               |
| Title     | Required. A short heading                                |
| Reference | The verse the prayer draws on, for example **John 3:16** |
| Body      | The prayer itself                                        |

Each entry in the list shows its date and reference. Search by title, reference, or the words of the prayer.

::: tip Write it to be prayed aloud
Short sentences and plain words work best on a phone screen. Aim for something that can be read in under a minute.
:::
