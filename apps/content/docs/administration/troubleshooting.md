# Troubleshooting

The messages you're most likely to see, what they mean, and what to do.

## Signing in

| You see                        | What it means                                     | What to do                                                             |
| ------------------------------ | ------------------------------------------------- | ---------------------------------------------------------------------- |
| Waiting for access             | Your account has no role yet                      | Ask a super admin for a role, then press **Check again**               |
| We couldn't check your access  | The studio couldn't reach the Kharis API          | Press **Try again**. If it keeps happening, tell a super admin         |
| This link doesn't work         | The invite or reset link has expired or been used | Ask a super admin to **Send password reset**, and use the newest email |
| Sign in again to upload files. | Your session ended while you were working         | Sign out, sign back in, and upload again                               |

## Saving

| You see                                        | What to do                                                     |
| ---------------------------------------------- | -------------------------------------------------------------- |
| An event needs a title.                        | Add a **Title**                                                |
| Choose a date and time.                        | Fill in the event's **Date** and **Start**                     |
| Add a title.                                   | Daily Reading and Daily Prayers entries need a **Title**       |
| Choose a sermon from the catalogue.            | On Daily Message, search and choose a sermon before scheduling |
| Add a video URL.                               | A featured video needs a **Video URL**                         |
| A visitor needs a name.                        | Add the visitor's **Name**                                     |
| Choose at least one branch for a branch admin. | Tick a branch in the invite, or choose a different role        |

## Uploading

| You see                                                                 | What to do                                                                         |
| ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| Images need to be 8MB or smaller.                                       | Resize or export the image smaller. See [Images & Video](/guides/images-and-video) |
| Videos need to be 95MB or smaller. Export a smaller copy and try again. | Export at 1080p or 720p and try again                                              |
| Choose an image file.                                                   | Use a JPEG, PNG, WebP, GIF, or AVIF                                                |
| Choose a video file (.mp4, .mov, or .webm).                             | Convert the video to one of those formats                                          |

## Something's missing

**A section isn't in my sidebar.** Your role doesn't include it. Check the [Access Reference](/administration/access-reference). If you need it, ask a super admin.

**A workspace is missing from the overview.** For branch admins, a workspace with none of Branches, Events, Messages, or Visitors is hidden.

**My change isn't on the website yet.** Refresh the page on the website. If it still hasn't appeared, check that the item is **Published** or **Active**, that it was saved in the right workspace, and, for events, that the right sites are ticked under **Show on**. [Where Content Appears](/guides/where-content-appears) shows which screen feeds which page.

**Grace is busy.** Wait a moment and ask again. See [Ask Grace](/studio/ask-grace).

::: tip Still stuck?
Note the page you were on, what you pressed, and the exact message, then send them to a super admin. A screenshot helps.
:::
