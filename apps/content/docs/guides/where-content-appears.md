# Where Content Appears

Which studio screen feeds which part of the websites and the app.

## kharis.org

| On the site                      | Edited in                                                                      |
| -------------------------------- | ------------------------------------------------------------------------------ |
| Locations and each branch's page | General → [Branches](/studio/branches)                                         |
| Events                           | [Events](/studio/events), with **Kharis website** ticked                       |
| Home page testimonies            | [Testimonies](/studio/testimonies) in General or Kharis Website, slot **Home** |
| Testimonies with giving          | Testimonies, slot **Giving**                                                   |
| Home page video                  | Kharis Website → [Featured Video](/studio/featured-video)                      |
| Department Discovery Quiz videos | [Department Videos](/studio/department-videos)                                 |

## kharis.org/kp2

| On the site | Edited in                             |
| ----------- | ------------------------------------- |
| Events      | Events, with **KP2 website** ticked   |
| Testimonies | Testimonies in General or KP2 Website |

## The Kharis app

| In the app     | Edited in                                           |
| -------------- | --------------------------------------------------- |
| Events         | Events, with **Mobile app** ticked                  |
| Announcements  | Mobile App → [Announcements](/studio/announcements) |
| Daily reading  | [Daily Reading](/mobile-app/daily-reading)          |
| Daily message  | [Daily Message](/mobile-app/daily-message)          |
| Daily prayer   | [Daily Prayers](/mobile-app/daily-prayers)          |
| Live broadcast | [Live](/mobile-app/live)                            |

## Coming in, not going out

Some screens collect what people send from the websites rather than publishing anything:

| From the websites | Arrives in                       |
| ----------------- | -------------------------------- |
| Contact forms     | [Messages](/studio/messages)     |
| Plan Your Visit   | [Visitors](/studio/visitors)     |
| Newsletter signup | [Newsletter](/studio/newsletter) |

::: tip Not sure?
Ask [Grace](/studio/ask-grace). Tell her what you want to change and she'll link you to the screen.
:::
