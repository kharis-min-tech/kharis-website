# Sermons

Sermons under **General** are the sermon records shown on the websites.

<Screenshot name="sermons" alt="Sermons page with a card per sermon showing speaker, date and Published or Draft" />

::: warning Two different sermon lists
The mobile app plays a separate catalogue, mirrored into Cloudflare from the church's sermon host. Records here do not appear in the app. To choose what the app plays on a given day, use [Daily Message](/mobile-app/daily-message). To look something up in the app's catalogue, use [Sermon Library](/mobile-app/sermon-library).
:::

## Adding a sermon

Press **New**.

| Field       | Notes                                  |
| ----------- | -------------------------------------- |
| Title       | Required                               |
| Speaker     |                                        |
| Date        | The date it was preached               |
| Series      | Groups sermons together on the website |
| Description |                                        |
| Video URL   | For example a YouTube link             |
| Audio URL   |                                        |
| Thumbnail   | Drop an image or paste a URL           |
| Published   | On by default                          |

Each card shows the speaker, date, and whether the sermon is **Published** or a **Draft**. Search by title, speaker, or series.

Super admins only.
