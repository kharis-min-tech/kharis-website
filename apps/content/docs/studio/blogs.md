# Blogs

Blogs are website posts for **kharis.org** and **KP2**. Author them in Content Studio now. They are **Experimental**: nothing is live on either website yet.

## Opening Blogs

**Kharis Website → Blogs** or **KP2 Website → Blogs**. Super admins only.

The list shows posts that include that site under **Show on**. Open either workspace to edit a post that is marked for both.

## Creating a post

1. Press **New blog**.
2. Set the **Title**, **Date**, and **Status** (Draft or Published).
3. Tick **Show on** for Kharis, KP2, or both.
4. Add an optional **Featured image**.
5. Write the **Content**.
6. Add **Gallery** images if you want more pictures with the post.
7. Press **Save blog**.

::: tip Experimental
Publishing a blog marks it ready for a future website release. It does not appear on kharis.org or KP2 until that feature ships.
:::

## Fields

| Field          | Notes                                               |
| -------------- | --------------------------------------------------- |
| Title          | Required                                            |
| Date           | The intended publish date                           |
| Status         | Draft or Published                                  |
| Show on        | Kharis website, KP2 website, or both                |
| Featured image | Optional cover picture                              |
| Content        | Plain text body                                     |
| Gallery        | Optional extra images; add or remove after drafting |

## List actions

| Action | What it does                        |
| ------ | ----------------------------------- |
| Edit   | Opens the post in the side panel    |
| Delete | Removes the post after confirmation |

Filter by status and search by title or body.
