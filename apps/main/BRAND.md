# Kharis homepage — brand bits we used

## Font

- Plus Jakarta Sans (Google Font)
- Body: medium/semibold
- Headings / big titles: bold / extra bold

## Main colours

- Purple (brand): `#630ED4` (same as KP2)
- Darker purple: `#4C08A8`
- Yellow (Jesus campaign): `#FFDE59`
- Soft purple background: `#F2EEF7`
- Soft off-white background: `#F8F6FA`
- Page white: `#FFFFFF`
- Main text: `#1C1C1F`
- Soft text: `#3A3A40`
- Muted text: `#4A4A52`

## Buttons (CTAs)

- Square corners, a thin darker edge underneath, soft shadow
- Main action → **purple** `#630ED4`, white text
- Second action → white with purple text
- Give → **yellow** `#FFDE59`, dark text
- Two buttons side by side are always the same width

## Simple rule

Purple = main brand + most CTAs  
Yellow = giving and the words that name us  
No pink, no rounded cards, no decorative gradients
