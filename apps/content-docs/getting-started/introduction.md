# Introduction

Welcome to the Content Studio documentation. This guide covers everything you need to know about keeping the Kharis websites and mobile app up to date, whether you look after one branch, run the church's communications, or manage who has access to the studio.

## Who is this for?

What you see in Content Studio follows from the role on your account. There are only three, and every page in this documentation is written with them in mind:

- **Super admins**: Edit everything in every workspace, and invite or remove studio users.
- **Branch admins**: Edit the branches they have been given, plus those branches' events, messages, and visitors.
- **No access**: Can sign in, but see nothing until a super admin gives them a role.

[Roles & Permissions](/getting-started/roles-permissions) explains exactly where each role's edges are.

## How to use this documentation

- If you're new, start with [What is Content Studio?](/getting-started/what-is-content-studio) and [Core Concepts](/getting-started/core-concepts).
- If you've just been invited, go to [Signing In](/getting-started/signing-in).
- If you need to understand who can do what, see [Roles & Permissions](/getting-started/roles-permissions) and the [Access Reference](/administration/access-reference).
- For a specific screen, use the **Studio** and **Mobile App** sections in the sidebar.
- For a task from start to finish, such as opening a new campus, use the **Guides**.

## What Content Studio covers

| Area              | What it does                                                                   |
| ----------------- | ------------------------------------------------------------------------------ |
| Overview          | Your day at a glance: counts, upcoming events, recent messages, quick actions  |
| Branches          | Campuses, pastors, venues, service times, photos, gallery, and branch video    |
| Events            | Services and gatherings, which sites show them, and weekly repeats             |
| Announcements     | News and notices for each website and the app                                  |
| Testimonies       | Stories for the websites, including the home and giving slots                  |
| Messages          | The contact form inbox for kharis.org and kharis.org/kp2                       |
| Visitors          | People who used Plan Your Visit, and whether they agreed to be contacted       |
| Newsletter        | Email addresses from the newsletter signup                                     |
| Sermons           | Sermon records shown on the websites                                           |
| Department Videos | The 24 ministry videos on the Department Discovery Quiz                        |
| Featured Video    | The video on a website's home page                                             |
| Mobile App        | Daily reading, daily message, daily prayers, Bible check, sermon library, live |
| Users             | Studio accounts, their roles, and their branches                               |
| Ask Grace         | A built-in guide that points you to the right screen                           |
