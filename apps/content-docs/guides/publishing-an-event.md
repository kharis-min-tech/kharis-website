# Publishing an Event

One event can be shown on the main site, KP2, and the app at the same time. This guide walks through adding one and choosing where it goes.

## 1. Open Events

Open the workspace you're working in, for example **Kharis Website**, and choose **Events**. Press **New event**.

## 2. Fill in the basics

<Screenshot name="event-editor" alt="The event editor panel with Show on ticked for the Kharis website and the mobile app" />

- **Title**, for example **Night of Worship**
- **Date** and **Start**, and an **End** if you know it
- **Branch**: the campus hosting it. Super admins can choose **No branch (all campuses)** for church-wide events
- **Category**: service, fellowship, conference, camp, or general

## 3. Choose where it shows

Under **Show on**, tick every site that should display the event:

| Tick           | The event appears on |
| -------------- | -------------------- |
| Kharis website | kharis.org           |
| KP2 website    | kharis.org/kp2       |
| Mobile app     | The Kharis app       |

The workspace you opened it from is ticked for you.

## 4. Add a cover image

Drop an image into **Cover image**. A wide photo works best.

## 5. Publish

Leave **Published** on and press **Save event**.

::: tip Weekly events
For something that happens every week, such as a midweek prayer meeting, choose **Weekly** under **Repeats** and tick the weekdays. Enter it once; every site works out the next date for itself.
:::

## Taking it down

To hide an event without deleting it, open it and turn **Published** off. Its card shows **Hidden**. To remove it for good, press **Delete**.
