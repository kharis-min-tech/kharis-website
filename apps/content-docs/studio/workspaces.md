# Workspaces

A workspace is where content belongs. Open one from the **Workspaces** list in the sidebar and its sections unfold underneath it, with the section you're on highlighted.

<Screenshot name="workspace" alt="The General workspace page with a card for each section and a count of its items" />

## The four workspaces

| Workspace      | Sections                                                                                        |
| -------------- | ----------------------------------------------------------------------------------------------- |
| General        | Branches, Department Videos, Sermons, Testimonies, Visitors, Messages, Newsletter, Users        |
| Mobile App     | Events, Announcements, Daily Reading, Daily Message, Daily Prayers, Bible, Sermon library, Live |
| Kharis Website | Branches, Department Videos, Events, Testimonies, Featured Video, Announcements, Messages       |
| KP2 Website    | Branches, Department Videos, Events, Testimonies, Announcements, Messages, Newsletter           |

## The workspace page

Each workspace has a home page with a card per section. Cards show how many items that section holds in this workspace, and a one-line description of what it's for. Click **Open** to go in.

## Which sections are shared

Some sections show the same list in every workspace. Others show each workspace its own.

| Section           | Behaviour                                                      |
| ----------------- | -------------------------------------------------------------- |
| Branches          | One list of campuses, wherever you open it                     |
| Department Videos | One set of 24 videos, wherever you open it                     |
| Sermons           | One list, under General                                        |
| Visitors          | One list, under General                                        |
| Events            | Each workspace has its own events                              |
| Announcements     | Each workspace has its own announcements                       |
| Testimonies       | Each workspace has its own testimonies                         |
| Messages          | Opens on the workspace's inbox, with a filter to see others    |
| Newsletter        | General shows every signup; KP2 Website shows KP2 signups only |

## Choosing a workspace

The workspace you're in is part of the address, as `?workspace=kharis` for example. If you open a workspace-specific section without one, such as from an old bookmark, the studio shows **Choose a workspace** with a button for each workspace that has that section.

## The unread badge

When you're inside a workspace, **Messages** in the sidebar shows a count of new messages for that workspace. It clears as messages are marked read or archived.

## Branch admins

Branch admins see each workspace with only the sections they can use: Branches, Events, Messages, and Visitors. **Mobile App** shows only Events. See [Roles & Permissions](/getting-started/roles-permissions#branch-admin).
