# Messages

Messages is the inbox for the contact forms on kharis.org and kharis.org/kp2. Every message is marked with the site it came from, so you always know whether someone wrote to the main site or KP2.

<Screenshot name="messages" alt="Messages inbox with status tabs, a workspace filter and search, and one message opened with Reply, Mark read, Archive and Delete" />

## The inbox

Each row shows:

- The sender's initials, with a gold dot while the message is **new**
- Their name, the topic, and the start of the message
- Where it came from: **Main site** or **KP2**
- Its status: **New**, **Read**, or **Archived**
- How long ago it arrived

When a message landed in a different inbox from the site it was sent on, a second badge shows the inbox, for example **KP2 inbox**.

## Filtering

| Control                     | What it does                                                                               |
| --------------------------- | ------------------------------------------------------------------------------------------ |
| All / New / Read / Archived | Show messages with that status                                                             |
| Workspace filter            | Opens on the workspace you came from. Choose **All workspaces** to see every inbox at once |
| Search                      | Matches name, email, topic, branch, and the message itself                                 |

The heading tells you how many new messages are in the current view.

## Opening a message

Click a row to open it. You'll see the full message, the sender's email, phone number if they gave one, the branch, and the exact date and time.

| Button    | What it does                                                                             |
| --------- | ---------------------------------------------------------------------------------------- |
| Reply     | Opens your email app with a reply addressed to the sender, subject **Re:** and the topic |
| Mark read | Moves it from New to Read. Shown only while the message is new                           |
| Archive   | Moves it out of the way. It stays searchable under **Archived**                          |
| Restore   | Brings an archived message back to Read                                                  |
| Delete    | Removes it permanently, after asking                                                     |

::: tip Reply from your own email
The studio doesn't send email itself. **Reply** opens a new message in your usual email app, so the conversation stays in your mailbox and the sender sees a real person's address.
:::

## The unread count

Inside a workspace, **Messages** in the sidebar shows how many new messages that workspace has. The **New messages** card on the [Overview](/studio/overview) shows the total across every inbox you can see.

## Branch admins

Branch admins see messages sent to their branches only. If nothing has come in yet, the inbox says so. See [Working the Inbox](/guides/working-the-inbox) for a routine that keeps it clear.
