# Newsletter

Newsletter lists the email addresses collected by the newsletter signup on the websites.

<Screenshot name="newsletter" alt="Newsletter page with a table of email addresses, their source site and signup date" />

## Which list you see

| Opened from | Shows                         |
| ----------- | ----------------------------- |
| General     | Every signup, from every site |
| KP2 Website | KP2 signups only              |

## The table

| Column    | Notes                          |
| --------- | ------------------------------ |
| Email     | Click to write to that address |
| Source    | **Main site** or **KP2**       |
| Signed up | Date and time of the signup    |

Search by email address with the box above the table. The count beside it shows how many subscribers are in view.

## Removing an address

Press **Remove** on the row. The studio asks first. Remove anyone who asks to unsubscribe as soon as you can.

::: tip Sending the newsletter
The studio collects addresses; it doesn't send newsletters. Use the church's email tool for that, and keep this list as the record of who signed up and where.
:::

Super admins only.
